# Design review: Ridgeline Walks (neutral test, A10)

Screenshots: `docs/screens/kit/ridgeline-*` and `sites/_demo_ridgeline/qa/shots/`.

The demo shares nothing recognisable with Bakers: different fonts (Barlow Condensed and Source Sans 3), a green and rust palette on parchment with a topographic texture, a split hero, a left aligned thesis, stacked feature blocks, a feature plus two offer layout, stat cards, a review grid, a split CTA and key fact pills. All eight layout variants differ from the Bakers rebuild.

It carries the full expedition set: route map with elevation, a day on the trail, departures table, packing list, who it's for, getting there, conditions this week, park alerts, the signature map and a timeline signature moment, plus the request to book flow (Group 2).

Round one self review against the B10 rubric, to be repeated by a separate reviewing subagent before any prospect work: first five seconds 4, thesis 4, imagery 3 (placeholders by design), typography 4, trust 4, path to booking 5, mobile 4, brand 4, copy 4, restraint 4, memorability 4.
